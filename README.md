
# ATELIER AI

Eine eigenständige, modulare und möglichst kostenlose KI-Lernplattform.

## Ziele
- Lernen für die gymnasiale Oberstufe in Bayern
- Zwölf Schulfächer
- Individuelle Lernunterstützung
- Lernmaterialien und Wissensdatenbank
- Offline-Funktionen
- Austauschbare KI-Modelle
- Keine kostenpflichtigen KI-Dienste

## Architektur
- Zentraler KI-Kern
- Sechs spezialisierte Lernmodule
- Gemeinsame Wissensbasis
- Lokale Speicherung
- Optionale Online-KI
